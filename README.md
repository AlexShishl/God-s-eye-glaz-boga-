# Глаз Бога 👁️

Шторка для MacBook (название в честь «Глаза Бога» из «Форсажа»).

Наводишь мышку на вырез камеры вверху экрана, и оттуда выезжает чёрная шторка с полезными штуками:

| Раздел | Что умеет |
|---|---|
| **Плеер** | Показывает, что играет, и управляет любым плеером: Музыка, Spotify, YouTube в браузере |
| **Скриншоты** | Каждый новый скриншот сам попадает сюда. Перетаскивай его куда нужно, удаляй крестиком ×. Хранится 12 часов |
| **Буфер обмена** | Последние 60 скопированных текстов, есть поиск, нажми на запись, и она снова скопируется |
| **Заготовки** | Почта, телефон, GitHub, Telegram, рабочая почта и всё, что добавишь сама. Нажала на блок, и текст скопирован. Поиск по названию |
| **Календарь** | Слева: встречи и задачи на сегодня плюс быстрое добавление. Справа: встречи на неделю. Работает с Google Календарём |
| **Лимиты нейросетей** | Строки внизу шторки: Claude (и Codex, если включить в настройках) — сколько израсходовано за 5-часовую сессию и за неделю, и когда сброс |
| **Переводчик** | Пишешь текст, перевод появляется сразу. Сам понимает русский ⇄ английский, есть другие языки |

Шестерёнка ⚙️ справа открывает **настройки**: там можно выключить ненужные разделы (они пропадут из шторки) и выбрать, лимиты каких нейросетей показывать (Claude, Codex).

Иконка 📌 справа закрепляет шторку, чтобы она не пряталась. `Esc` закрывает её.

## Как установить (один раз, минут 5)

1. Открой **Терминал** (⌘ Пробел → «Терминал»).
2. Если Xcode ещё не установлен, поставь инструменты разработчика:
   ```
   xcode-select --install
   ```
3. Перейди в папку с проектом и собери приложение:
   ```
   cd ~/Downloads/notch-drawer
   bash build.sh --install
   ```
4. Приложение само попадёт в «Программы» и запустится.
   Если macOS скажет «не удаётся проверить разработчика»: открой «Программы», правый клик по «Глаз Бога» → **Открыть** → **Открыть**.
5. Вверху в строке меню появится иконка шторки. Там можно включить **«Запускать при входе»**.

Нужна macOS 14 Sonoma или новее.

## Как обновлять

В строке меню нажми на 👁 → **«Обновить…»**. Откроется Терминал, скачает свежую версию с GitHub,
соберёт её и перезапустит приложение. Ничего распаковывать руками не надо.

## Разрешения, которые попросит macOS

- **Календарь и Напоминания**: для раздела «Календарь» (кнопка «Разрешить доступ»).
- **Универсальный доступ**: чтобы кнопки плеера управляли *любым* плеером. Плеер подскажет ссылкой.
  Настройки → Конфиденциальность и безопасность → Универсальный доступ → включи «Глаз Бога».
- **Рабочий стол**: чтобы забирать новые скриншоты.
- **Связка ключей**: один раз спросит доступ к «Claude Code-credentials». Нажми **«Разрешать всегда»**, это нужно для строки с лимитами.
- **Автоматизация (Музыка / Spotify)**: чтобы видеть название трека.

> После каждой пересборки через `build.sh` macOS может снова спросить про Универсальный доступ.
> Это нормально: выключи и включи «Глаз Бога» в списке.

## Как подключить Google Календарь

Настройки → **Интернет-аккаунты** → **Google** → войди и включи **Календари**.
Встречи сразу появятся в шторке, а новые встречи можно записывать прямо в Google-календарь
(выбери его в списке «Календарь», когда добавляешь встречу).

## Если что-то не так

- **Плеер не показывает название трека** (например, YouTube в браузере): в новых версиях macOS Apple закрыла
  чужим приложениям доступ к «Сейчас играет». Кнопки ⏮ ⏯ ⏭ всё равно работают с любым плеером.
  Название трека точно видно для Музыки и Spotify.
- **Скриншот появляется с задержкой**: это из-за превью в правом нижнем углу. В разделе «Скриншоты» нажми **«Сразу в шторку»** (или ⌘⇧5 → Параметры → сними «Показывать плавающую миниатюру»).
- **Скриншоты не появляются**: проверь, что разрешила доступ к Рабочему столу. Если скриншоты сохраняются
  в другую папку (⌘⇧5 → Параметры), шторка сама её найдёт.
- **Лимиты Claude Code не видны**: в Терминале запусти `claude` и войди в аккаунт. У Claude Code нет «дневного» лимита, есть 5-часовая сессия и недельный, их и показываем.
- **Переводчик пишет «Проверь интернет»**: ему нужен интернет.

Где лежат данные: `~/Library/Application Support/NotchDrawer/` (заготовки, история буфера, полка скриншотов).
